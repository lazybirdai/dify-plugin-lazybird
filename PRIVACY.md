# Privacy policy

The Lazybird plugin for Dify sends data to one service: the Lazybird API at `api.lazybird.app`.

## What the plugin sends

- **The text you turn into speech**, and the voice you picked, to generate the audio.
- **Your Lazybird API key**, to sign each request. Dify stores the key in its own encrypted credential store.
- **A language code**, when your app sets one, to list matching voices.

## What the plugin stores

The plugin itself stores, logs and shares nothing. It has no analytics or tracking, and it does not collect any user data of its own.

## How Lazybird handles the data

Lazybird processes the text to generate speech and keeps usage records for billing, as described in the [Lazybird privacy policy](https://lazybird.app/privacy). Lazybird does not sell your data.

## Contact
